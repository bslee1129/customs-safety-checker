GitHub 저장소 연동 가이드

이 프로젝트는 로컬 Git 저장소(customs-safety-checker)로 초기화되어 있으며, 사용자님의 GitHub 계정(https://github.com/)에 바로 원격 저장소를 연결하여 푸시할 수 있습니다.

GitHub에서 새 저장소(New Repository) 생성

1. 브라우저에서 https://github.com/new에 접속합니다.
2. Repository Name에 customs-safety-checker (또는 원하는 이름)을 입력합니다.
3. [Create repository] 버튼을 클릭합니다.

로컬 프로젝트와 GitHub 원격 저장소 연결 (터미널 명령)

# 1. 프로젝트 폴더로 이동
cd d:\AX붐업\범정부AX\customs-safety-checker

# 2. 첫 커밋 생성
git add .
git commit -m "feat: 관세청 AI 스마트 검사관 v2.0 초기 릴리스"

# 3. 브랜치명을 main으로 설정
git branch -M main

# 4. 나의 GitHub 원격 저장소 연결 (사용자 아이디로 변경)
git remote add origin https://github.com/<사용자아이디>/customs-safety-checker.git

# 5. GitHub에 푸시
git push -u origin main

실행 방법 (Local Run)

# 가상환경 파이썬으로 FastAPI 서버 실행
..\Customs_AI_Bot\venv\Scripts\python.exe server.py
# 접속 주소: http://localhost:8000
